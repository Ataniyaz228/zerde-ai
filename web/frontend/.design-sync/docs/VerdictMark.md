# VerdictMark

Branded verdict marks — one "stamp-frame" motif (a rounded-square seal), not generic lucide circles: `good` = frame + check (confirmed), `bad` = frame + diagonal strike (contradicted), `warn` = dashed frame + dash (no data / open question). Colour inherits from `currentColor`, so it picks up the surrounding status colour. `size` is in px.
