# Button

Single button primitive — `primary` / `secondary` / `ghost` / `icon` variants in `sm` / `md` / `lg`. Renders an `<a>` when `href` is set, otherwise a `<button>`. The primary variant is filled near-black ink (not the brand colour); touch target is always ≥ `--tap-min`. Use `block` to stretch full-width on mobile.
